# case-09-research-finance｜把科研人员的时间还给科研

FDE团队帮一家央企科研机构把报销和财务处理里到处找审批、判断费用归属、反复填集团系统的工作接了起来，科研人员在钉钉发来发票后，AI整理相关信息、辅助判断和发现异常，再让自动化程序填报，最后逐步落地了10个财务相关场景，让科研人员少跑流程、财务少做重复操作。
