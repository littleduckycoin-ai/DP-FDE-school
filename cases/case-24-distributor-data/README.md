# case-24-distributor-data｜每个经营数字都能回到原始数据

FDE团队帮一家通过经销商卖到中国和越南的澳洲奶酪企业解决总部只看得见发货、看不清终端卖了多少和市场费用是否合理的问题，把经销商的表格、票据和图片整理成统一口径，接进原系统，异常带着原始依据交给人审核，让周会少花时间对数；访谈称费用问题发现比例从不到10%提高到约30%，这些数字做过脱敏。
