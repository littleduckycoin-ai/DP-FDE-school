# case-21-fire-design-drafts｜专业初稿要保留可控的调整空间

FDE团队帮建筑设计人员解决消防施工图里要逐个房间布喷头、消火栓，还得反复查规范和随平面改图的问题，用专门的CAD解析模型和规则引擎先生成可调整的图纸初稿，让大型项目约30分钟就能先出一版，再由设计师改参数、审结果；这30分钟不包含最终专业审核和完整交付。
