# case-07-team-ai-collaboration｜把个人AI能力变成团队方法

FDE团队帮一家基金公司的研发团队解决了大家各用各的AI、文档和分工跟不上新工具的问题，通过五天半的现场培训和后续迭代，和产品、开发等角色一起做出可共用的需求说明文档与协作方法，让个人用AI逐步变成团队一起用AI，不过这家基金公司没有公开完整的提效或收益数字。
