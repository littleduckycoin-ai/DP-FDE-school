# case-22-inventory-advertising｜让库存真正影响补货与广告

FDE团队帮一个做东南亚服装电商的十几人团队解决几千个SKU的库存、物流照片、补货和广告各管各的问题，把原SaaS数据接到飞书，让AI先识别照片、按原规则整理补货单，再让人确认，并把库存变化连到广告调整上，物流图片和数据处理从每天四五小时缩到一小时以内；后续利润效果没有完整跟踪。
