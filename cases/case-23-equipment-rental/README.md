# case-23-equipment-rental｜为老板接住被放弃的长尾需求

FDE团队帮一家工程设备租赁企业解决老板忙着大客户、顾不上零散小订单的问题，把询价先按大小和复杂程度分开，让系统收集车型、操作员、油费、距离和作业要求，算出报价区间并做初步沟通，复杂订单再交回老板，让过去容易漏掉的小客户开始有人接；项目才推进一个多月，新增收入还没有可靠统计。
