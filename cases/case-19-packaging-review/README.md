# case-19-packaging-review｜把审核前置到研发协作中

FDE团队帮消费品企业解决新产品包装排队审核、研发和渠道经验散在人脑里的问题，先观察真实协作，再和审核人员一起把检查事项拆清楚，用识别工具读取包装、用固定程序算营养数值，设计稿提交后先做预审、疑难处交给人，让专家少查低级错误，也把每次驳回和修改的经验留下来。
