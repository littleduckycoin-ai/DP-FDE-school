# case-20-supply-chain-visibility｜把ERP数据变成可解释的经营状态

FDE团队帮一家汽车维修零部件供应商解决ERP里有订单、采购和库存，老板却仍要到处问进度、查付款缘由的问题，在原ERP上把这些记录重新关联，做成经营看板和飞书异常提醒，让未收齐的货和应付款对应的业务更容易追踪；系统刚上线，尚不能证明利润或成本已经改善。
