# 把思考留在线上

学习过程中可直接说：“我是alice，昵称小艾；请把本次会话中我的思考、评价和问题逐轮追加到学校的线上学习记录。”替换为自己的标识和昵称。

## 反馈如何发布

具备GitHub写入连接的Agent在一次明确授权后，复用你的案例学习记录Issue，每轮追加评论并返回线上链接。旧观点保留，更正另起一条修订；同伴反馈写在自己的主题里并引用对方。

当前Agent只能读时，先正常学习。它会整理好可复制内容，给你[在线学习记录表单](https://github.com/littleduckycoin-ai/DP-FDE-school/issues/new?template=learning-note.yml)；你在GitHub登录后选择案例、填写标识与昵称并提交。一次在线反馈不要求克隆、建立本地项目、fork或发教材PR。

提交成功的帖子和评论可立即供同学在线阅读。没有成功回执或仅有草稿时，Agent应明确“待提交”。不要把账号密码或令牌贴进对话。仓库公开，发布前使用适合公开的内容。

## 学校怎样沉淀教材

学员表达先留在线上主题。维护者或获得授权的Agent定期将有价值的记录归档到对应`reflections/`，保留原链接和稳定ID。

案例canon、跨案例patterns仍先标proposed，经CODEOWNER审核的PR合并后才成为正式拆解。GitHub连接或文件API可以直接在线创建文件和PR，学员无需学习Git命令。没有真实审核不得预填accepted、审核人或共识。

来源勘误需要说明证据，并同步维护Markdown、JSON、索引和受保护的基础摘要。详见[治理规则](governance.md)。
