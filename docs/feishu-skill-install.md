# 飞书学校：学员安装与开始

安装完整的 `.codex/skills/school-guide` 文件夹，包含 scripts 和 references。分发站点只存放安装包，学习资料与个人沉淀均直接读写飞书。

把安装包交给 Codex 后说：

> 请安装这个压缩包中的 school-guide，保留完整目录。只安装 Skill 和连接工具，不下载教材。

下一轮说：

> 使用 $school-guide，帮我完成首次飞书连接并开始学习第一个案例。我的展示名是张三，学习标识是 zhangsan。我同意你把本次学习中适合分享的思考、评价和问题自动保存到对应案例的 reflections，保存后给我链接；我说“不记录”的内容不要上传。

首次需要本人完成飞书网页配置和授权。Agent 会准备 CLI 并提供真实链接。有可用连接时复用；没有连接时，当前 CLI 可能需要先创建个人应用，组织审批要求仍然适用。安装包没有共享账号或密钥，不能代替个人授权。

学校首页：https://dptechnology.feishu.cn/docx/J5Uad8uqAoBNtyxkWfKcCSbZnQb

个人沉淀保存在对应案例 reflections 文件夹下的署名飞书文档正文。每人、每例、每天一份，逐轮追加；保存成功会返回实际链接。只生成了草稿或授权尚未通过时，Agent 会明确说明未保存。
